# Results

## Real-data validation highlights

- Parsed 4,129,628 ClinVar variants into a working variant knowledge graph.
- Built EDS and collagen-focused universes for discovery.
- Recovered a disease-driving PLOD1 pattern with lowest-energy bitstring 0001 at -5.0.
- Identified a tightly interacting B3GALT6 spondylodysplastic EDS cluster with pairwise J = +1.2 and lowest-energy bitstring 1101 at -4.0.
- Validated a real chr22 / 1000 Genomes QAOA pilot from genotype matrix to measured bitstrings.

## Public positioning

This repository presents a real-data discovery framework, not a clinical product. Findings are computationally generated hypotheses and ranked discovery signals, not medical claims.
