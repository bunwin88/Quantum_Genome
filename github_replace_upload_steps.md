# Upload Steps

## GitHub
1. Create a new public repository named `quantumgenome-eds-discovery-engine`
2. Upload the contents of this folder, not the zip itself
3. Commit message: `Initial public release: QuantumGenome EDS Discovery Engine`

## LinkedIn
1. Add a Project section
2. Project title: `QuantumGenome EDS Discovery Engine`
3. Paste the description from `linkedin_project_entry.md`
4. Add media -> add a link -> paste the GitHub repository URL
5. Add the same link to Featured
6. Publish a post using `linkedin_post.md`
